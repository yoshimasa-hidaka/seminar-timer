# 研究会 講演タイマー

Mac で起動し、iPad に大きな残り時間を表示、Mac から操作する Web タイマー。
依存パッケージなし（Node 標準ライブラリのみ）・ネット接続不要（同一 WiFi で完結）。

## 使い方

1. `start.command` を Finder でダブルクリック（または ターミナルで `node server.js`）
2. **操作画面（Mac）は自動でブラウザが開きます**。上部に iPad 用の URL と QR が出ます
3. **iPad** で QR を読む（または URL を入力）→ 表示ページが開く → **一度タップ**して音声有効化＆全画面
4. Mac と iPad は **同じ WiFi**（会場 WiFi が無ければ Mac のインターネット共有）に

> ポート 8080 が使用中なら自動で 8081… に切り替えます（URL のポート番号は起動ログ／操作画面で確認）。

## はじめての人へ（渡すとき・受け取ったとき）

このアプリは **Node.js** で動きます。受け取った人が最初の一回だけ確認すること：

1. **Node.js を入れる**：未インストールなら `start.command` が案内を出します。
   [nodejs.org](https://nodejs.org/) の **LTS 版**をインストール → 再度ダブルクリック。
2. **「開発元を確認できない」と出たら**（ネット/メール/AirDrop で受け取ったファイルの保護）：
   `start.command` を **右クリック →「開く」→「開く」**（初回だけ。以後は普通にダブルクリック）。
3. **ダブルクリックでテキストエディタが開いてしまう**場合（zip 展開で実行権限が外れた）：
   ターミナルで `chmod +x start.command` を一度実行するか、上記の右クリック→開く。
4. **終了**：起動した黒いウィンドウで `Ctrl + C`（閉じるとサーバも止まります）。

> フォルダごと zip にして渡すのが簡単です（macOS の「アーカイブユーティリティ」で展開すれば
> 実行権限は保たれます）。インターネット接続は不要・外部送信なし。

## 機能

- **講演フェーズ**と**質疑応答フェーズ**を分けて管理（例：講演20分＋質疑10分）
  - iPad には現在のフェーズ（講演 / 質疑応答）と残り時間を大きく表示
  - 講演時間が来たら自動で質疑フェーズへ移行（早く終わったら「質疑応答へ」で手動移行も可）
- **鈴の作法**（iPad のブラウザで鳴る）
  - **1鈴**（予鈴）= 各フェーズ終了の数分前。**講演と質疑で別々に設定可**（例：講演5分前・質疑2分前）
  - **2鈴** = 講演終了 → 質疑へ
  - **3鈴** = 質疑終了（全体終了）→ 以降は赤点滅で超過カウント
- **色分け**：緑（通常）→ 黄（予鈴以下）→ 赤＋点滅（超過）
- **講演者に時間の範囲が伝わる表示**：講演中はバッジに「講演（質疑応答は別）」、
  大きい数字の下に「全体のこり MM:SS（質疑応答こみ）」を併記
- **終了予定の壁時計**（例：終了予定 14:35）を実行中に表示
- **メッセージ**：Mac から「あと5分」等を iPad 画面下部にフラッシュ表示
- **日本語 / English** 切替（操作画面・iPad 表示・クイックメッセージが連動）
- **iPad のスリープ防止**（Screen Wake Lock）— 長い講演でも画面が眠らない
- 開始/一時停止/リセット、±10秒/±1分の微調整、講演・質疑・予鈴・タイトル設定

## 操作画面（Mac）の便利機能

- **プリセット**：「20+10 / 30+15 / 45+15 / 60+0」をワンタップで設定（詳細設定内）
- **シンプルなメイン画面**：普段使う操作だけ表に出し、数値設定・ベル確認・接続情報は
  `詳細設定` に畳んである
- **キーボード操作**：スペース＝開始/一時停止、R＝リセット、Q＝質疑へ、T＝講演に戻す、
  ←/→＝±10秒、↑/↓＝±1分
- **Mac でもベルを鳴らす**：右上のトグル（ON で緑）。会場スピーカーに Mac を繋ぐ運用向け
- **iPad 接続を最上部に常時表示**：表示ページの URL を上部に出し、タップで QR（詳細設定）を展開。
  QR はオフライン生成・依存パッケージなし。iPad のカメラで読めば IP 手入力不要
- **表示中メッセージの確認**：iPad に出ているメッセージを操作画面にも表示（消し忘れ防止）

## インターネットは不要（完全オフライン動作）

このアプリは外部に一切アクセスしない（CDN・外部フォント・外部 API なし。QR もローカル生成）。
**ネットの無い会場でもそのまま動く。** 必要なのは Mac と iPad の間の「ローカルな通信経路」だけ。

会場 WiFi が無い／使えないときは、外部ネット無しで 2 台だけの閉じた WiFi を作る：

- **方法1：Mac を親機にする（おすすめ）** — システム設定 →「インターネット共有」を ON。
  Mac が出す WiFi に iPad を接続する。インターネット接続が無くてもこの方式は機能する
  （その場合 Mac の IP は `bridge100` 等に乗るが、サーバは自動で検出して URL/QR に反映する）。
- **方法2：iPad を親機にする** — iPad の「インターネット共有」を ON、Mac をそれに接続。
- **会場 WiFi がある場合**でも、ゲスト WiFi が **AP isolation**（端末間通信の遮断）だと
  Mac↔iPad が繋がらないことがある。そのときも上の方法1/2 に切り替える。

> いずれの場合も、起動ログと操作画面の QR に出る URL を iPad で開けば OK。
> iPad は表示ページを開いたら **一度画面をタップ**（ベルの音はこの操作後に鳴る）。

## 構成

- `server.js` … HTTP + SSE サーバ（状態の唯一の真実。毎秒、全クライアントへ配信）
- `public/display.html` … iPad 表示
- `public/control.html` … Mac 操作
