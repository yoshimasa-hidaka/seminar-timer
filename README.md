# 研究会 講演タイマー / Seminar Talk Timer

**日本語** | [English](README.en.md)

研究会・セミナーの講演時間を管理するタイマー。**Mac で起動し、iPad に大きく残り時間を表示、Mac から操作**する。
依存パッケージゼロ（Node 標準ライブラリのみ）・**完全オフライン動作**（外部送信なし）。

---

## 使い方（クイックスタート）

1. `start.command` を Finder でダブルクリック（または ターミナルで `node server.js`）
2. **操作画面（Mac）が自動でブラウザに開く**。上部に iPad 用の URL と QR が出る
3. **iPad** で QR を読む（または URL を入力）→ 表示ページを開く → **一度タップ**して音声有効化＆全画面
4. Mac と iPad は **同じ WiFi**（会場 WiFi が無ければ Mac のインターネット共有）に

> ポート 8080 が使用中なら自動で 8081… に切替（ポート番号は起動ログ／操作画面で確認）。

## はじめての人へ（渡すとき・受け取ったとき）

このアプリは **Node.js** で動く。受け取った人が最初の一回だけ確認すること：

1. **Node.js を入れる**：未インストールなら `start.command` が案内を出す（古い版なら警告も）。
   [nodejs.org](https://nodejs.org/) の **LTS 版**をインストール → 再度ダブルクリック。
2. **「開発元を確認できない」と出たら**（ネット/メール/AirDrop 経由の保護）：
   `start.command` を **右クリック →「開く」→「開く」**（初回だけ）。
3. **ダブルクリックでテキストエディタが開く**場合（zip 展開で実行権限が外れた）：
   ターミナルで `chmod +x start.command`、または上記の右クリック→開く。
4. **終了**：起動した黒いウィンドウで `Ctrl + C`。

> フォルダごと zip で渡すのが簡単（macOS のアーカイブユーティリティで展開すれば実行権限は保たれる）。

## 機能

### タイマー（2フェーズ）
- **講演フェーズ**＋**質疑応答フェーズ**を分けて管理（例：講演20分＋質疑10分）。
- 講演時間が来たら**自動で質疑へ移行**。早く終わったら「質疑応答へ」で手動移行も可。
- iPad に現在のフェーズ（講演 / 質疑応答）と残り時間を大きく表示。
- **大きい数字をクリック**すると「現フェーズの残り ⇄ 全体（質疑込み）の残り」を切替（iPad・操作画面とも同期）。
- **終了予定の壁時計**（例：終了予定 14:35）を実行中に表示。

### 鈴の作法（ベル）
- **予鈴**＝講演終了の数分前。**予鈴1・予鈴2 の2回**まで設定可（例：5分前と1分前）。予鈴2は既定オフ（0で無効）。
- **講演終了で2鈴** → 質疑へ／**質疑終了で3鈴**（全体終了）→ 以降は赤点滅で超過カウント。
- **色分け**：緑（通常）→ 黄（予鈴以下）→ 赤＋点滅（超過）。
- **手動ベル**：操作画面の 🔔1 / 🔔2 / 🔔3 でいつでも鳴らせる。

### ベル音（合成・外部ファイル不要）
- **音色**：チャイム / ベル / ビープ から選択（選ぶとその場で試聴）。
- **音量スライダー**・**高さ（ピッチ）スライダー**。
- **iPad 音 / Mac 音を個別に ON/OFF**（会場スピーカーに Mac を繋ぐ運用などに対応）。

### メッセージ
- Mac から「あと5分」等を **iPad 画面上部に大きくフラッシュ表示**（クイック文 ＋ 自由入力）。
- 表示中のメッセージは操作画面にも出る（消し忘れ防止）。

### 操作画面（Mac）
- **プリセット**（例：10+5 / 15+5 / 25+5 / 30+10 / 45+15）をワンタップで設定。**自由に追加・編集・削除可**（予鈴も含めて記憶）。
- **時間設定は即反映**（個別入力欄・−／＋ステッパー）。
- **キーボード操作**：スペース＝開始/一時停止、R＝リセット、Q＝質疑へ、T＝講演へ、←/→＝±10秒、↑/↓＝±1分。
- **誤操作防止**：進行中は時間設定とリセットを無効化／プリセット削除は確認あり。
- **日本語 / English** 切替（操作画面・iPad 表示・メッセージが連動）。

### iPad 表示
- **スリープ防止**（Screen Wake Lock・iPadOS 16.4+）。確実にしたいときは端末設定の自動ロックを「なし」に。
- ホーム画面に追加すると Safari の UI が消えて全画面に。

### 設定の保存
- 持ち時間・予鈴・ベル音/音量/ピッチ・iPad音・プリセット・言語・表示スコープを **`config.json` に自動保存**し、**再起動しても復元**（走行中の時計は保存しない）。`config.json` は端末ごとのローカル設定（リポジトリには含めない）。

## オフライン・接続について

外部に一切アクセスしない（CDN・外部フォント・外部 API なし。QR もローカル生成）。**ネットの無い会場でも動く**。必要なのは Mac↔iPad のローカル通信経路だけ。

会場 WiFi が無い／使えないときは、外部ネット無しで2台だけの閉じた WiFi を作る：

- **方法1：Mac を親機にする（おすすめ）** — システム設定 →「インターネット共有」ON。Mac の出す WiFi に iPad を接続。ネット接続が無くても機能する（Mac の IP が `bridge100` 等でもサーバが自動検出して URL/QR に反映）。
- **方法2：iPad を親機にする** — iPad の「インターネット共有」ON、Mac をそれに接続。
- 会場 WiFi があっても **AP isolation**（端末間通信の遮断）だと繋がらないことがある。その時も方法1/2 へ。

> iPad は表示ページを開いたら **一度画面をタップ**（音声はこの操作後に有効化）。鳴らない時は端末の音量／消音（コントロールセンターのベルマーク）も確認。

## 構成

| ファイル | 役割 |
|---|---|
| `server.js` | HTTP + SSE サーバ（状態の唯一の真実・SSE で全クライアントに配信・設定永続化） |
| `public/control.html` | Mac 操作画面 |
| `public/display.html` | iPad 表示画面 |
| `public/bell.js` | ベル音合成（WebAudio・両画面で共用） |
| `public/qr.js` | QR コード生成（オフライン・依存なし） |
| `start.command` | Finder からダブルクリック起動 |
| `config.json` | 実行時に保存される設定（gitignore・端末ごと） |

依存パッケージなし。Node.js（macOS）で動作。Linux/他環境でも `node server.js` で起動可（macOS 固有はブラウザ自動オープン・IP 自動検出程度）。
